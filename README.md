# KhojKr – Tourist Place Finder 🌍

KhojKr is a web-based application that helps users discover and explore tourist destinations easily.
The platform allows users to search for tourist places and view important details about them in a simple and user-friendly interface.

---

## 🚀 Features

* 🔍 Search for tourist places
* 📍 View information about different destinations
* 🧭 Simple and easy-to-use interface
* 📱 Responsive design for better user experience
* 💾 Data stored using MySQL database

---

## ⚙️ How to Run the Project

1. Clone the repository

```
git clone https://github.com/your-username/khojkr-tourist-finder.git
```

2. Move the project folder to **htdocs** in XAMPP

3. Start **Apache** and **MySQL** in XAMPP

4. Import the database in **phpMyAdmin**

5. Open in browser

```
http://localhost/khojkr
```
